Command Input
Enter one command per line, or use REPEAT n [commands]

Command Reference

FORWARD n
Move turtle forward n pixels
BACK n
Move turtle backward n pixels
LEFT deg
Turn turtle left by deg degrees
RIGHT deg
Turn turtle right by deg degrees
PENUP
Lift pen (move without drawing)
PENDOWN
Lower pen (draw while moving)
HOME
Return turtle to center, heading 0°
CLEAR
Clear canvas, reset turtle to home
REPEAT n [commands]
Execute commands n times
