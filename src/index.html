Command Input

Command Reference

Movement
  • FORWARD n / FD n — Move forward n units
  • BACK n / BK n — Move backward n units
  • RIGHT deg / RT deg — Turn right deg degrees
  • LEFT deg / LT deg — Turn left deg degrees
  • SETXY x y — Set absolute position
  • SETHEADING deg / SETH deg — Set heading
Pen Control
  • PENUP / PU — Lift pen
  • PENDOWN / PD — Lower pen
  • PENCOLOR r g b — Set pen color (0-255)
  • PENSIZE n — Set pen width
Control Flow
  • REPEAT n [commands] — Repeat commands n times
  • IF condition [commands] — Conditional execution
State & Screen
  • HOME — Return to origin, heading 0
  • CLEARSCREEN / CS — Clear canvas
  • SHOWTURTLE / ST — Show turtle
  • HIDETURTLE / HT — Hide turtle
